# شبکه اجتماعی | The Social Network

تجربهٔ وب سینمایی معرفی و نقد فیلم *The Social Network* (2010)

## لینک سایت (بعد از فعال‌سازی Pages)

`https://USERNAME.github.io/REPO-NAME/`

## فعال‌سازی GitHub Pages

1. Settings → Pages
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Save

فایل اصلی باید `index.html` باشد (همین ریپو همین‌طور است).

## محتویات

- `index.html` — کل سایت (یک فایل)
- `.nojekyll` — برای جلوگیری از پردازش Jekyll در GitHub Pages

عکس‌ها و تریلر از اینترنت بارگذاری می‌شوند؛ اینترنت لازم است.
